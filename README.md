# Bug Bounty Website

## Deskripsi Project
Proyek ini adalah sebuah platform website "Bounty Bug" sederhana yang memungkinkan pengguna untuk mendaftar dan melaporkan celah keamanan (bug) pada sebuah sistem untuk mendapatkan reward. Proyek ini dibangun menggunakan HTML dan CSS murni.

## Cara Menjalankan
1. Clone repositori ini ke komputer lokal menggunakan perintah: `git clone <URL_REPO_KAMU>`
2. Buka folder proyek di dalam text editor (misalnya VS Code).
3. Buka file `index.html` menggunakan web browser (Chrome/Firefox/Edge) atau menggunakan ekstensi Live Server di VS Code.

## Dokumentasi Perintah Git yang Digunakan
* `git init`: Menginisialisasi folder lokal menjadi repositori Git baru.
* `git clone`: Menggandakan repositori dari GitHub ke komputer lokal.
* `git add .`: Memasukkan semua perubahan file ke dalam staging area sebelum di-commit.
* `git commit -m "pesan"`: Menyimpan perubahan ke riwayat Git secara permanen beserta pesan singkat.
* `git push origin <branch>`: Mengirimkan commit dari laptop (lokal) ke GitHub (remote).
* `git pull origin <branch>`: Menarik dan menggabungkan pembaruan terbaru dari GitHub ke laptop lokal.
* `git branch <nama>`: Membuat cabang (branch) baru.
* `git checkout <nama>`: Berpindah dari satu branch ke branch lainnya.
* `git merge <branch>`: Menggabungkan riwayat dari branch lain ke dalam branch yang sedang aktif.
* `git rebase -i`: Melakukan rebase interaktif (digunakan untuk memadatkan/squash beberapa commit menjadi satu).
